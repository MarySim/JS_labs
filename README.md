# Лабораторная работа №4: Асинхронность

## Задание 1
Функция `ask_password(login, password, success, failure)` проверяет пароль. Пароль правильный, если содержит ровно 3 гласные (a,e,i,o,u,y) и такой же набор согласных, как в логине. При успехе вызывает `success(login)`, при ошибке `failure(login, error)`.

## Задание 2
Асинхронные функции `readConfig`, `doQuery`, `httpGet`, `readFile` выполняются последовательно двумя способами:
- **a. Коллбэки** – вложенные вызовы
- **b. Уведомители** – через переменную-счётчик step

## Задание 3
Вычисление `F(x) = f1(x) + f2(x) + ... + fn(x)`, где все `fi(x)` – асинхронные. Промежуточный результат передаётся на каждом шаге.

Открыть `index.html` в браузере, смотреть консоль (F12).
